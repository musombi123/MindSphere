## Important

The GitHub connector exposed the filenames and binary metadata, but did not make the JPEG pixels available for visual inspection in this editing session. For that reason, this map intentionally does **not** claim that a particular file is a front-face portrait, side profile, hairstyle, beard, or full-body outfit. Please make the images available in the chat or label which file is which; then this map can be completed accurately and the GLB likeness can be checked against them.

The Google Photos share link supplied by the project owner could not be opened from this environment. Download the selected photos from that album and add them to \`public/reference/player/\` as well. The actual player is loaded from \`public/assets/characters/player.glb\`; reference photographs are used during avatar authoring, not automatically treated as runtime 3D models.
